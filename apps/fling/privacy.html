Fling privacy policy

Last updated: 25 November 2026

Who uses it

Fling is a personal app used only by its developer on their own email accounts. It is not offered to the public.

What it accesses

With your permission, Fling uses the Gmail API (scope gmail.modify) to read your messages and their headers, and to archive, trash, label, mark as read and restore them when you ask it to. For other providers such as Yahoo it connects over IMAP with an app password you supply.

Where your data is kept

Message details and sign-in tokens are stored on the owner's own computer in a local database and configuration file. They are not uploaded to any server run by the developer, and they are never sold, shared or used for advertising.

Optional summaries

If summaries are turned on, the text of an email is sent to Google's Gemini API to produce a short summary. They are off unless configured.

Google API Services User Data Policy

Fling's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

You can revoke Fling's access at any time at myaccount.google.com/permissions. Deleting the app's local database and configuration file removes all data it stored.

Contact

Questions: use the support email shown on Fling's Google sign-in screen.
